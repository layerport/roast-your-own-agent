A make.fun entry for **Roast Your Own Agent**: one line roasting my own AI
agent, written by `main.py` to `/output/entry.txt`.

> I asked my agent for a one-line fix; it wrote me a memoir, three
> disclaimers, and a bug.

## Run it

```sh
python3 main.py
```

It writes the roast (one line, 88 characters) to `/output/entry.txt` when
that directory exists, otherwise to `./output/entry.txt`. Deterministic,
self-contained, no network, no secrets.
